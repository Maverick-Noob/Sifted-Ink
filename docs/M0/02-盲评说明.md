# M0 · Q2 盲评说明（手法规格 vs 直接模仿）

> **目的**：验证"删除模仿作家、改用可执行手法规格"这个决定**没有让读感变差**。
> **判据**：盲评中手法规格版（B）的读感分 **≥ 模仿版（A）的 85%**。

---

## 1. 生成样本

```bash
export ANTHROPIC_API_KEY=sk-...
python tools/m0_ab.py --model claude-sonnet-4-6 --chapters 3 --technique fast-climax
```

产出：

```
m0_output/
  A/  chapter_01.txt  chapter_02.txt  chapter_03.txt   ← 旧写法（模仿公版作家）
  B/  chapter_01.txt  chapter_02.txt  chapter_03.txt   ← 手法规格
  C/  chapter_01.txt  chapter_02.txt  chapter_03.txt   ← 不指定
  blind_key.json      ← 揭盲用，**不要给盲评者看**
```

**先跑 `--dry-run` 确认提示词**（不花钱）：

```bash
python tools/m0_ab.py --dry-run
```

三组的**用户提示完全相同**，唯一变量是风格指令 —— 这是这个测试成立的前提。

---

## 2. 组卷（关键一步）

**不要把 A/B/C 目录名给盲评者**。按下面方式打乱并重命名：

1. 把 9 个文件（3 组 × 3 章）收集到一个扁平目录
2. 随机重命名为 `sample_01.txt` … `sample_09.txt`
3. **自己**保存映射表（哪几号是 A / B / C）—— `blind_key.json` 已有，但它记的是
   原文件名，重命名后需要更新
4. 把打乱后的目录发给盲评者，**只给这个目录**

> ⚠️ 章节之间有连续性（A 的第 2 章接第 1 章）。两种处理方式：
> - **推荐**：每个受试者读**同一顺序**的 9 段（打乱后固定顺序），比较段落本身
> - 备选：只评第 1 章（3 段），牺牲数据量换干净对比

---

## 3. 打分表（每位盲评者一份）

对每段打三个 1~10 分：

| 维度 | 问自己什么 |
|---|---|
| **读感** | 我想不想读下去？好不好看？ |
| **像不像人写的** | 这段话像不像人说的？（**不是问"是不是 AI 写的"**） |
| **节奏** | 读起来累不累？有没有平的地方？ |

再打两个整体印象（可选，但很有信息量）：

- 哪一段你**最想跳过**？（最差）
- 哪一段你**最想接着读**？（最好）

> **注意措辞**：问"像不像人写的"而不是"AI 率多少"。
> 检测器有 10-32% 的误判率，人也未必更准；我们要测的是**读感**，
> 而读感是可以直接打分的。

---

## 4. 判据

揭盲后统计三组的平均分：

| 情形 | 结论 |
|---|---|
| B ≥ A × 85% | ✅ **创新点 3 成立** —— 删除模仿作家没有损失效果，无需回退 |
| A × 70% ≤ B < A × 85% | ⚠️ 手法规格不够用 → **先补规格**再测一轮（增加 sample_paragraph 数量、增加"节拍"类参数） |
| B < A × 70% | ❌ 手法规格不成立 → 只保留**公版**作家并明确风险提示；或彻底放弃风格控制这条线 |

**同时看**：
- C 组（不指定）如果反而最高 → 说明**默认叙事已经够好**，手法规格的价值需要重新论证
  （但这仍然是**好消息**：说明手法规格不会让文变差，只是增益有限）
- "最想跳过"集中在某一组 → 看具体是哪一段，判断是风格问题还是内容问题

---

## 5. 附带收获（务必记录）

- 受试者**主动提到**的"这句读起来假" → 直接进 `diversity.py` 的禁用词表
- 受试者说"太啰嗦/太干/太文艺" → 对应到手法规格的哪一项参数？记下来
- 有没有受试者说"这像某个作家的风格" → **这正是我们要避免的**，记下来并检查是哪条提示词漏了

---

## 6. 受试者与成本

- **5 位**中文写作者（网文 2、公众号/盐选 2、纯文学 1）
- 每位读 9 段 ≈ 25 分钟 → 合计约 2 小时
- API 成本：9 段 × 约 1200 输出 token ≈ **¥2~3**（Sonnet）或 **¥0.2**（国产模型）
- **不要用"我朋友说"代替盲评** —— 礼貌性认可会毁掉整个结论

---

## 7. 别做的事

- ❌ 别告诉受试者"有一组是新方案"—— 会污染
- ❌ 别只评第 1 章就下结论（数据量太小）
- ❌ 别用"更好/更差"两档打分—— 分辨率不够，用 1~10
- ❌ 别在揭盲前讨论结果
