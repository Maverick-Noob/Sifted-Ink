## 0. 总体结论

项目**功能完整度与产品设计水平相当高**（多 Agent 架构、RAG 记忆、大纲择优、动态节奏、Web SSE 实时推流都已落地，代码可读性也优于同类开源 AI 写作工具）。但作为**要交付、可被他人安装运行、可被社区协作**的工程项目，它存在三类硬伤：

1. **工程基座为零** —— 0 个测试、0 个 CI、0 个锁文件、0 个打包元数据、0 个 issue/PR 模板、0 个 CHANGELOG。代码改了没人知道有没有坏，依赖漂了没人知道。
2. **安全姿态与部署姿态不匹配** —— Web UI 硬编码 `host="0.0.0.0"` 且**无任何鉴权**，而表单会接收 API Key 并用它发起计费调用；同时 `{{ novel_text | safe }}` 存在存储型 XSS 注入面；SDK 异常原文（OpenAI 的报错信息里会带 key 前缀）会经 SSE 推给浏览器。
3. **文档与实现脱节** —— 超时 15 vs 30 分钟、MIT vs Apache 2.0、117 vs 183 位作家、宣称 MOBI/AZW3 但 `FORMATS` 只有 4 项、地区人数错位、`NOVEL_FONT_PATH` 逃生舱实际不可达。这些不是措辞问题，会直接导致用户按文档操作后失败。

**综合评分：3.8 / 10**（纯 PoC 可用度 7.5 / 10；可交付度 3.0 / 10）

### 2.1 安全（维度 4）

| 编号 | 严重度 | 证据 | 问题 | 建议 |

| **S-01** | **Critical** | `webui/app.py:920`、`novel_preactor.py:126` | **Web UI 硬编码绑定 `host="0.0.0.0"`，且全站零鉴权。** `/api/start` 表单接收 API Key 并用它发起计费调用；`/api/stream/{run_id}`、`/api/status/{run_id}`、`/download/{run_id}/...` 无任何凭证校验。同一局域网内任意设备访问 `http://<你的IP>:8000` 即可：① 盗用你的 Key 无限烧钱；② 读取所有历史 run 的小说与评估日志 | ① CLI 增加 `--host`（**默认 `127.0.0.1`**），`--web` 显式传 host；② 加一个可选的 `SIFTED_INK_WEB_TOKEN` 简易鉴权中间件（`Authorization: Bearer` / `?token=` 查 header 优先），未设置时仅允许 127.0.0.1 访问；③ README 顶部加"默认仅本机可访问"的安全说明 |

### 2.7 正确性缺陷（顺带发现，与工程质量强相关）

| 编号 | 严重度 | 证据 | 问题 |
|---|---|---|---|
| **B-01** | **High** | `naming.py:220-228` | **候选书名兜底列表全部产出 Python 函数的 repr。** `fallbacks = [f"{p}的传奇", f"{p}战记", f"{p}: {theme}", f"{loc}故事", f"{event}", f"{p}与{loc}"]` —— `p`/`loc`/`theme`/`event` 都是**函数对象**（应调用 `p()`），所以 6 个兜底全部会变成 `"<function p at 0x7f9c...>的传奇"`。这些兜底**不做长度/合法性校验**（`2 <= len(name) <= 30` 只作用于主循环），一旦模板循环凑不满 10 个唯一候选，函数 repr 就会成为真实书名 → 直接进文件名与 EPUB 元数据 |

**如何 mock LLM 避免烧钱（核心设计）**

全项目**只有一个** LLM 出口：`LLMClient.call()`（`agents.py:255`）。因此只需**一个** mock 缝：

```python
# tests/conftest.py
import pytest
from novel_preactor.agents import LLMClient

class FakeLLM:
    """按 prompt 关键字返回预置响应；未命中则抛错（防止测试悄悄烧真钱）。"""
    def __init__(self, script: dict[str, tuple[str, int]]):
        self.script = script
        self.calls: list[tuple[str, str]] = []   # 便于断言 prompt 内容

    async def call(self, system_prompt, user_message, max_tokens=None, temperature=0.8):
        self.calls.append((system_prompt, user_message))
        for key, (text, tokens) in self.script.items():
            if key in system_prompt or key in user_message:
                return text, tokens
        raise AssertionError(f"未预置的 LLM 调用: {system_prompt[:80]}")

@pytest.fixture
def fake_llm(monkeypatch):
    def _install(script: dict):
        fake = FakeLLM(script)
        monkeypatch.setattr(LLMClient, "call", fake.call)   # 全局打桩
        return fake
    return _install
```

配套约定：
1. **默认不联网** —— `conftest.py` 里加 `autouse` fixture，检测到 `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` 等环境变量存在时 **monkeypatch `socket.socket` 使其抛错**，任何漏网的真实调用立刻失败。
2. **契约测试用"黄金样本"** —— 把 5~8 条真实 LLM 输出（脱敏后）存为 `tests/fixtures/llm/*.json`，作为 fixture 喂给 mock，既不烧钱又贴近真实分布。
3. **每个 mock 脚本都要断言调用次数**（`fake_llm.calls` 长度），防止"某个 agent 没被调用"这种假绿。

**CI 怎么跑**

- 触发：push / PR（必须）、`workflow_dispatch`（手动）、schedule（每晚，含真实供应商冒烟）
- 步骤：`ruff check` → `mypy` → `pytest -q --cov`（3.10/3.11/3.12/3.13 矩阵）→ `bandit -r .` → `pip-audit`
- 速度：单元+契约应在 **30 秒内**跑完；E2E 用 `TestClient` 不起真实端口
- 国内友好：pip 源用 `https://pypi.tuna.tsinghua.edu.cn/simple`（`--index-url`），缓存 `~/.cache/pip`；GitHub Actions 在国内访问 PyPI 慢时镜像更快

## 4. 依赖与打包改进方案（摘要）

完整 `pyproject.toml` 草案见 **§5**；核心结论：

- **应该出 `pyproject.toml`**：现在 `pip install .` 不可用、无法声明 `requires-python`、无法做 extras、无法进 PyPI。
- **应该做 extras 分组**：核心只留 4 个包，其余按需装。
- **应该出锁文件**：用 `uv lock`（最快）或 `pip-tools` 生成并提交；CI 装锁文件。
- **一次装 13 家 SDK 不合理（但现状也没装 13 家）**：13 个 provider 里 10 个复用 openai SDK，只需 3 个独立 SDK（anthropic / openai / google）。**应把 `google-generativeai` 换成 `google-genai`**，顺带解掉 `httpx<0.28` 这个历史 pin。
- **Python 版本**：3.10+ 声明与实际语法一致（PEP 604 `X | None` 要求 3.10）—— 只需在 `pyproject.toml` 里机器可读地写出来。

**改进方案（按优先级）**

**P0 — 立刻做（半天工作量）**

1. **密钥脱敏工具**（`utils.py` 新增）：
   ```python
   _SECRET_PATTERNS = [
       (re.compile(r"sk-[A-Za-z0-9_\-]{6,}"), "sk-REDACTED"),
       (re.compile(r"AIza[0-9A-Za-z_\-]{20,}"), "sk-REDACTED"),
       (re.compile(r"(?i)bearer\s+[A-Za-z0-9._\-]{10,}"), "Bearer sk-REDACTED"),
       (re.compile(r"(?i)(api[_ -]?key\"?\s*[:=]\s*)\"?[^\s\"',}]{6,}"), r"\1sk-REDACTED"),
   ]

   def redact_secrets(text: str) -> str:
       """把任何看起来像 API Key 的片段替换为 sk-REDACTED。"""
       if not text:
           return text
       for pat, repl in _SECRET_PATTERNS:
           text = pat.sub(repl, text)
       return text
   ```
2. **日志过滤器**（兜底）：`class RedactingFilter(logging.Filter): def filter(self, record): record.msg = redact_secrets(str(record.msg)); record.args = ...; return True`，挂到 `narrative_prism` logger 与 FileHandler 上。
3. **异常回显前脱敏**：`webui/app.py:351` 改为 `_update_status(run_id, "error", f"出错: {redact_secrets(str(e))}")`；`app_logger.error(f"Run {run_id} failed: {redact_secrets(str(e))}", exc_info=True)`（**注意 traceback 里的局部变量仍可能含 key —— 建议 traceback 只写 DEBUG 级，或对 traceback 文本也过一遍脱敏**）。

**P1 — 本周做**
