## Q1 · 作者愿不愿意逐章介入（半天）

### 物料
- 2 张界面截图：**A = 当前"一键出整本"流程**，**B = 逐章"生成 → 编辑 → 采纳"流程**
- 一份 90 秒的录屏动图（若来不及，两张截图也够问）

### 访谈脚本（每个作者 8 分钟，只问 4 个问题）

1. 你现在用 AI 写东西吗？用在哪一步？（**先听，别推销**）
2. 看图 A：你会在哪一步按下"开始"？然后去干嘛？
3. 看图 B：每章都要你看完改完再点"采纳"，这个循环你能接受吗？为什么？
4. 如果一周要写 6 千字，这两种方式你选哪个？**为什么**（追到具体场景，别接受"都还行"）

> **注意**：不要问"你觉得哪个好"，要问"你选哪个、为什么"。前者只会得到礼貌的赞同。

### 判据
- 愿意逐章 ≥6/10 → 保留创新点 1，UI 做成默认逐章、批量作为高级选项
- 3~5/10 → 做成"双模式"，默认仍是批量但把逐章作为"精品模式"引导
- ≤2/10 → **推翻创新点 1**，回到"一键出整本"，把创新点全部转向内容侧（Q2/Q3）

### 成本
0 元。只需 10 个微信好友/作者 QQ 群。

## Q2 · 手法规格 vs 直接模仿（一天）

### 物料
- 同一故事设定（用 `story_config.yaml` 的林远），3 组参数：
  - **A 组**：旧写法（提示词注入「请模仿 X 的风格 + 代表作」）
  - **B 组**：新手法规格（`narrative_techniques.json`）
  - **C 组**：不指定（默认）
- 每组生成 **3 章**（约 ¥8 × 3 ≈ ¥24）
- 提示词示例（供受试者理解"手法规格"长什么样）：

```
### 可执行规格（必须逐条遵守）
- 叙事人称：第三人称限知
- 句长：中位约 12 字，长句不超过 24 字
- 对话占比：约 30%
- 描写占比：约 35%
### 禁用表达（命中即视为不合格）
眼中闪过一丝、嘴角勾起、心中五味杂陈
```

### 盲评方法
1. 邀请 **5 位**中文写作者（网文/公众号/小说各覆盖），**不告诉他们哪组是哪组**
2. 每位受试者读 A/B/C 各 3 章（共 9 段），每段打 3 个 1-10 分：
   - **读感**（好不好看、想不想读下去）
   - **像不像人写的**（不是"AI 率"，是"这句话像不像人说的"）
   - **节奏**（读起来累不累、有没有平的地方）
3. 揭盲后统计：A / B / C 的平均分

### 判据
- B（手法规格）读感分 ≥ A（直接模仿）的 **85%** → 创新点 3 成立，删除作家模仿功能
- B < A 的 70% → 手法规格不够用，**先补规格**（增加 sample_paragraph 数量、
  增加"节拍"类参数）再测一轮；仍不过则只保留**公版**作家并明确风险提示

### 附带产出
- 受试者对"可执行规格"哪种写法最敏感的反馈 → 直接回写到 `narrative_techniques.json`
- 哪个指标读起来最"假" → 直接进 `diversity.py` 的禁用词表

### 成本
约 ¥25（3 组 × 3 章）+ 受试者时间。

## Q3 · 诊断仪能不能识别"AI 味"（一天）

### 采集 30 段真实网文
- 来源：起点/番茄/知乎盐选等平台的**公开章节**（用于内部评估，不用于训练）
- 采样规则：
  - **15 段** 公认读感好、AI 味轻的开篇
  - **15 段** 公认"AI 味重"或被读者吐槽机械的段落
  - 每段 **800~3000 字**
- 打标：每段由 2 人独立打「AI 味重 / 中 / 轻」三档，不一致由第三人裁定

### 跑诊断仪
```python
from novel_preactor.diversity import analyze_text, diagnose
report = diagnose(text)          # report["score"] 0~100，越高越有变化
```

### 评估
- 计算 `score` 与人工"AI 味"三档标签的 **Spearman 相关系数**
- 目标 **≥ 0.6**；≥0.75 视为可用（可对外宣传"节奏体检"）
- 同时人肉检查：把分数排最高的 5 段和最低的 5 段拿出来看，**指标说的对不对**

### 判据
- 相关 ≥0.6 → 指标成立，进入 M1（把诊断卡接到结果页）
- 0.4~0.6 → 保留但只作为"参考"，不作为评分；继续调参考区间
- <0.4 → **参考区间是错的**（`_REFERENCE` 字典是凭经验写的，必须用这 30 段重新标定）
  → 改法：把 `_REFERENCE` 换成从语料算出的分位数，**并把标定脚本一起提交**

### 成本
0 元（人工投入约 1 天）。

## 别做的事

- ❌ 不要用"我觉得"代替访谈数据——五个创新点里有三个的价值假设是**可测的**，测了就不用争
- ❌ 不要在 Q2 里让受试者知道"这是我们要推的方案"——会被礼貌性认可污染
- ❌ 不要用 AI 生成的段落当 Q3 的"AI 味重"样本——**真实网文里的 AI 味段落**才有诊断价值
- ❌ 不要跳过 Q3 的**人工标签**——没有标签就没有相关性，没有相关性指标就是自说自话
