# docs/research — 研究素材（非运行时数据）

本目录下的文件**不参与运行时**，不会被加载，也不会被打包进发行版
（见 `pyproject.toml` 的 `package-data` 白名单）。

## `author_corpus.json`

2026-10-21 之前，仓库根目录有一个 `writing_style.json`：183 位作家的风格描述 + 代表作 + 卒年 +
公版标记，写手提示词会直接注入「请模仿 **{作家名}**」与代表作名。

**该功能已移除**，原因：

1. 183 位中仅 12 位进入公有领域（去世 50 年以上），其余 171 位（93.4%）在世或去世不足 50 年；
2. 著作权保护**具体表达**，不保护创作方法。把「像某位在世作家」做成产品卖点，
   等于把最大的法律风险挂在最显眼的位置；
3. 平台侧已把「AI 粗制滥造」「是否严重缺乏原创性」列为治理维度。

**这个文件只作为历史留档保留在本地**（已加入 `.gitignore`，**不入库、不打包**）。
它此前的版本曾经以 `writing_style.json` 的名义提交过，因此仍存在于 git 历史中——
要彻底清除需要重写历史（`git filter-repo`），该操作会改写所有提交，请自行评估。

**使用规则**：

- ❌ 不要把它挪回仓库根目录
- ❌ 不要把它加入 `package-data`
- ❌ 不要在提示词、UI、文档里重新引入作家名或代表作名
- ✅ 现行使用的叙事手法规格在 `narrative_techniques.json`，其中不含任何作家名或作品名

> 若要彻底清掉历史包袱，需要重写 git 历史（`git filter-repo`）。该操作会改写所有提交，
> 请自行评估后再做。
